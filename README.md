# 🐢 Turtle Race Game

A fun and interactive **Turtle Race Game** built with Python's `turtle` module. Players can place a bet on which turtle will win the race and watch the race visually on the screen.

---

## 🎮 Features
- Place a bet on a turtle's color before the race.
- Watch 6 turtles race across the screen.
- Finish line and race track lines for better visualization.
- On-screen winner announcement with celebratory message.
- Colorful and interactive UI.

---

## 🛠️ Requirements
- Python 3.x
- No additional libraries required (uses built-in `turtle` module)
